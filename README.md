# Thai NLP Condominium Search Prototype (Lifestyle Criteria)
ระบบค้นหาคอนโดมิเนียมจากข้อความภาษาธรรมชาติภาษาไทยตามเงื่อนไขไลฟ์สไตล์

โครงงานวิจัยปริญญานิพนธ์ สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยนวัตกรรมดิจิทัลเทคโนโลยี มหาวิทยาลัยรังสิต (ปีการศึกษา 2569)
- **ผู้วิจัย**: นางสาว วาธิณีย์ วรรณกิจ (รหัสนักศึกษา 6707225)
- **อาจารย์ที่ปรึกษา**: อาจารย์ สุมนา เกษมสวัสดิ์

## ฟังก์ชันการทำงาน
1. **Single Search Interface**: ค้นหาผ่านข้อความภาษาไทยในช่องเดียว
2. **Entity Extraction 4 มิติ**:
   - 🚇 ทำเล / สถานีรถไฟฟ้า BTS & MRT
   - 🐾 นโยบายการอนุญาตเลี้ยงสัตว์ (Pet-Friendly)
   - ✨ บรรยากาศและไลฟ์สไตล์ (เช่น เหมาะกับ WFH, เงียบสงบ, เป็นส่วนตัว)
   - 💰 ช่วงงบประมาณค่าเช่า (เช่น ราคาไม่เกิน 12,000 บาท/เดือน)
3. **Interactive Prototype**:
   - ป้ายผลการสกัดเอนทิตีแบบเรียลไทม์
   - ป๊อปอัปดูรายละเอียดข้อมูลโครงการคอนโดมิเนียม
   - ปุ่ม Home รีเซ็ตหน้าแรก และปุ่มสลับดูห้องพักทั้งหมด

## โครงสร้างไฟล์
- `index.html`: โครงสร้างหน้าเว็บและส่วนแสดงผลการค้นหา
- `style.css`: ธีม Modern Luxury Indigo Glassmorphism
- `app.js`: ระบบ Thai NLP Entity Extraction และตรรกะการคัดกรอง
- `data.js`: ชุดข้อมูลคอนโดมิเนียมตามแนวรถไฟฟ้า BTS/MRT
